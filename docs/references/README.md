# Style references

`pebble-reference.png` is the screenshot Marcus supplied for the Pebble style on September 7, 2026. It is retained unchanged as design context for the implementation brief. It is not shipped in the studio or used by the renderer. Its original creator and license are unknown; review whether to retain it before making this repository public.

`field-birds.svg` is original deterministic renderer artwork for seed `field-notes:20`, retained as the visual reference for Field Birds. Regenerate with `avatars render --style field-birds --seed field-notes:20`. Full contact sheets and icon/circle examples come from `scripts/prove-field-birds.sh`.
